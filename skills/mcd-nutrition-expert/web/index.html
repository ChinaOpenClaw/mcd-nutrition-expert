建立你的营养档案

基于 Mifflin-St Jeor 公式计算基础代谢，按 FAO/WHO 活动系数换算总消耗， 再按 ACSM 建议分配三大营养素。档案仅保存在本机 SQLite，不上传任何服务器。

SP 矩阵 · 餐品选型定位

横轴 = 营养密度（蛋白质+碳水 / 热量，越右越饱腹高效）； 纵轴 = 钠负担（钠 / 热量，越上钠负荷越重）。金色十字 = 你的目标点。 距离目标点越近的餐品，越贴合你的营养处方。
